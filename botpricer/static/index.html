ИНТЕГРАЦИЯ

Подключение Telegram

Аккаунт читает источники, бот публикует в вашем канале.

Загрузка состояния…

1. Доступы

API ID и API hash получите на my.telegram.org/apps. Токен бота — у @BotFather. Добавьте бота администратором своего канала.

Секреты не показываются повторно. Они хранятся локально в папке data, которая исключена из Git.

2. Вход в аккаунт для чтения каналов

Программа читает только добавленные вами каналы. Для закрытого источника аккаунт должен уже иметь доступ.

ПРОВЕРКА ФОРМАТА

Проверка прайса

Вставьте сообщение поставщика, чтобы проверить распознавание без публикации.

Каждая строка: полное название товара и цена в рублях. Модель, память, цвет и регион указывайте в одной строке. Фото, PDF и прайсы с общими заголовками пока не распознаются.

# BotPricer

Локальная программа с веб-панелью для чтения прайсов из Telegram-каналов, расчёта наценки и публикации предложений в своём канале.

## Быстрый запуск на Windows

1. Установите **Python 3.11 или новее** с [python.org](https://www.python.org/downloads/). При установке включите Python Launcher (`py`).
2. Скачайте репозиторий: **Code → Download ZIP**, распакуйте архив.
3. Запустите **`start.bat`**. При первом запуске он создаст виртуальное окружение и установит зависимости. При последующих запусках проверит необходимые зависимости.
4. Откроется панель: **http://127.0.0.1:8000**. Консоль оставьте открытой.

Никакая отдельная СУБД, платный API или Docker не нужны. Панель доступна только на этом компьютере, без регистрации и пароля.

Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python run.py
```

## Первое подключение

1. В разделе **Подключение Telegram** сохраните `API ID` и `API hash` с [my.telegram.org/apps](https://my.telegram.org/apps).
2. Создайте бота через [@BotFather](https://t.me/BotFather), сохраните его токен в том же разделе.
3. Введите номер аккаунта, запросите код и подтвердите вход. Если включена двухэтапная проверка, панель запросит её пароль. Пароль и код не сохраняются в базе.
4. Добавьте бота администратором своего канала с правом публикации сообщений.
5. В **Настройках** укажите свой канал, наценку и контакт для заказа. Сохраните, затем нажмите **Проверить права бота в канале**.
6. В **Каналах-источниках** добавьте поставщиков по `@username` или `https://t.me/username`. Для закрытого канала аккаунт должен уже быть участником; вместо приглашения укажите числовой ID вида `-1001234567890`.
7. Сначала проверьте реальные сообщения поставщиков в **Проверке прайса**. Нажмите кнопку проверки цен на странице **Обзор**, посмотрите **Товары и цены → Посмотреть будущие объявления**.
8. Когда результат устраивает, включите автопубликацию и ежедневное расписание. По умолчанию обе функции выключены.

Учетная запись читает добавленные источники через Telethon. Бот публикует и редактирует карточки через Bot API. Управление выполняется через веб-панель; отдельного меню команд внутри Telegram в этой версии нет.

## Обучение и ответы на вопросы

При первом открытии панели появляется обучение из шести шагов: знакомство с программой, подключение Telegram, добавление поставщиков, проверка формата прайса, настройка наценки и просмотр объявлений перед отправкой.

- Кнопки **Далее** и **Назад** переключают объяснения и показывают нужный раздел панели.
- Обучение только знакомит с интерфейсом: оно не подключает аккаунты и не публикует объявления.
- Если обновить страницу, обучение продолжится с сохранённого шага.
- Его можно завершить или пропустить. После этого при обычном открытии оно больше не появляется.
- Для повторного просмотра откройте **Помощь и ответы → Пройти обучение заново**.

Прогресс обучения хранится в этом браузере на этом компьютере. В другом браузере или после очистки его данных обучение появится снова. Настройки поставщиков и цены хранятся отдельно и от этого не меняются.

В разделе **Помощь и ответы** собраны вопросы о первом подключении, ключах Telegram, выборе каналов, сроке действия цен, форматах прайса, наценке, отправке объявлений, ошибках и ежедневном расписании. Нажмите на вопрос, чтобы раскрыть ответ. На странице **Обзор** также остаётся короткая инструкция первого запуска.

## Формат прайсов в первой версии

Поддерживаются текст сообщения и подпись к медиа. Одна строка — один товар с полным названием и ценой в рублях:

```text
iPhone 15 128 Black US — 61 000 ₽
iPhone 15 256 Blue EU — 68 500 ₽
Sony WH-1000XM5 Black — 25 900 ₽
iPhone 15 128 Pink EU — 62 000 ₽ нет в наличии
```

Разделители: тире, знак равенства, вертикальная черта или пробел. Цены `61000`, `61 000`, `61.000`, а также копейки `61 000,50` распознаются. Поддерживается только RUB: валютный пересчёт отсутствует.

Флаги распространённых регионов, русские названия основных цветов, `Apple iPhone` / `айфон`, `128 GB` / `128 ГБ` нормализуются. Остальные характеристики сохраняются в ключе товара, включая регион, состояние и SIM. Нечёткое совпадение не применяется: разные или неполные обозначения могут остаться отдельными товарами. Перед автопубликацией проверьте одинаковое обозначение вариантов у поставщиков. Для iPhone обязательно наличие объёма памяти в каждой строке; прочие характеристики должны быть указаны поставщиком полностью.

Не распознаются изображения прайсов, PDF, таблицы-вложения, общие заголовки с моделью над несколькими строками и сложные сокращения поставщиков. Такие сообщения требуют адаптации парсера по примерам. Нераспознанные строки видны в панели. В сообщении с двумя ценами одной нормализованной позиции обе строки отправляются на проверку.

## Правила источников

- **Отдельные товары / изменения**: сообщения дополняют каталог. Для каждой пары «источник + товар» берётся наиболее позднее изменение. Если новое сообщение явно указывает «нет в наличии» с ценой, оно отменяет старое предложение того же источника.
- **Полный прайс**: последнее распознанное сообщение целиком заменяет прайс источника. Все позиции должны находиться в одном сообщении. Если в выбранном сообщении есть нераспознанные строки, обновление источника отклоняется, старые данные сохраняются. Не выбирайте этот режим для прайсов, разбитых на несколько постов.
- **Срок актуальности** считается от даты публикации или изменения сообщения, а не от даты его чтения. Истёкшие предложения и предложения под заказ не участвуют в выборе цены.
- Новые сообщения читаются за заданный период. Уже сохранённые сообщения отдельно перечитываются по ID для обнаружения правок и удаления. При превышении лимита сканирования источник считается непроверенным; увеличьте лимит или уменьшите период.
- Из доступных актуальных предложений выбирается самое дешёвое. При отключении или удалении источника его цены исключаются из каталога.

Строка «нет в наличии» без цены сейчас отправляется на проверку и не отменяет старое предложение немедленно; оно перестанет участвовать по сроку актуальности. Используйте прайсы в поддерживаемом формате.

## Цены и публикация

- Фиксированная наценка: `закупка + сумма + доставка`.
- Процент: `закупка × (1 + процент / 100) + доставка`.
- Комбинированная: `закупка + max(процент от закупки, минимум) + доставка`.
- Итог округляется вверх до указанного шага. Денежные расчёты используют целые копейки и `Decimal`.

Каждая карточка связана с ID канала и ID сообщения. Повторная проверка не создаёт новый пост, если карточка уже существует. Неизменившиеся карточки не отправляются повторно. Если подходящих предложений больше нет, карточка редактируется в «Нет в наличии». Если хотя бы один источник не удалось проверить, массовое снятие товаров с наличия пропускается на этом запуске.

Изменение относительно последней опубликованной цены выше заданного порога блокируется. В **Товарах и ценах** разрешите новую цену, затем запустите обновление. Разрешение действует только для конкретной суммы. Полной ручной фиксации цен и индивидуальных наценок по товарам в этой версии нет.

При сетевом сбое во время отправки результат может быть неизвестен. Карточка получает статус проверки; новая отправка автоматически не повторяется. Проверьте свой канал и укажите ID уже созданного поста либо явно разрешите повтор. После аварийного перезапуска незавершённые отправки также требуют проверки. Не удаляйте локальную базу: она содержит связи с постами.

Кнопка **Пауза публикаций** выключает автопубликацию, в том числе дальнейшие операции текущего запуска. Уже отправленный Telegram запрос может завершиться. Сбор цен и расписание продолжают работать.

## Расписание и хранение

По умолчанию время — **09:00, Europe/Moscow**. После включения программа выполняет одну плановую попытку в местный календарный день. Если приложение открыто после установленного времени, оно выполняет пропущенную попытку этого дня. Пропущенные прошлые дни не воспроизводятся. Ошибочную попытку можно повторить вручную. После изменения времени в тот же день дополнительный плановый запуск не выполняется, если попытка дня уже была.

Для автоматической работы программа должна быть запущена, а компьютер — включён и подключён к интернету. Закрытие консоли останавливает приложение. Запускайте только один экземпляр из одной папки. Панель не предназначена для открытия в интернет; для серверного размещения потребуется отдельная настройка доступа.

Папка `data/` создаётся автоматически и содержит SQLite-базу с настройками, исходными сообщениями, историей цен и сессией Telegram. Секреты хранятся локально без шифрования средствами приложения; ограничьте доступ к этой папке. Для резервной копии остановите программу и скопируйте **всю папку `data/`**. Она исключена из Git вместе с сессиями и окружениями.

## Разработка и проверки

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Тесты проверяют парсинг и сопоставление, расчёт цен, срок актуальности, редактирование и удаление прайсов, сохранение данных при ошибках, отсутствие повторов, подтверждение скачков цен, расписание, API и сокрытие секретов. Telegram в тестах заменён тестовыми адаптерами; реальный вход, доступ к каналам и публикация требуют ваших доступов и отдельной проверки.

Проверка интерфейса в Chromium (порт 8000 должен быть свободен):

```bash
python -m playwright install chromium --only-shell
python -m scripts.check_ui
```

Сценарий использует временную базу и проверяет обучение при первом открытии, сохранение шага после перезагрузки, завершение и пропуск обучения, повторный запуск из помощи, раскрытие ответа на вопрос, действия с каналами, сохранение настроек, парсер и мобильную вёрстку. Снимки экрана создаются в `test-results/`.

Основные файлы:

| Файл | Назначение |
|---|---|
| `run.py`, `start.bat` | Запуск локальной программы |
| `botpricer/app.py` | HTTP API и панель |
| `botpricer/telegram.py` | Чтение каналов, вход и Bot API |
| `botpricer/parser.py` | Разбор и нормализация строк |
| `botpricer/pricing.py` | Наценка, округление, текст карточки |
| `botpricer/db.py` | SQLite, каталог и предложения |
| `botpricer/worker.py` | Проверки, публикация и расписание |
| `botpricer/static/` | Интерфейс без сборки frontend |
| `tests/` | Автоматические проверки |

Для изолированного тестового запуска путь данных можно изменить переменной окружения `BOTPRICER_DATA_DIR`. Токены, пароли и сессии не добавляйте в репозиторий.
